# Kissa Aur Seekh

Daily 1-minute Hindi moral-story YouTube Shorts for the **Kissa Aur Seekh** channel.

- `setup.sh` – installs everything and downloads the Hindi voice model
- `engine/` – characters, backgrounds, voice, cover maker, `build.py`
- `stories/` – one folder per story (script, scenes, music)
- `videos/` – finished videos waiting to be published (old ones are removed)
- `log/state.json` – what is published and what is queued
- `CLAUDE.md` – step-by-step instructions for the daily automatic run
